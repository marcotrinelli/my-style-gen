# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-15

First public release.

### Added

- `my-style-gen` skill: reads material one person authored and writes an installable
  `my-style` skill in return.
- Claude Code plugin packaging — `.claude-plugin/plugin.json` and a `marcotrinelli`
  marketplace catalogue.
- A/B harness under `assets/ab-test/` for measuring a generated skill with and without
  it loaded.

### Changed

- Renamed from `my-style-generator` to `my-style-gen`.
